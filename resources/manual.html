YG DATA 使用手册

数据处理自动化流程 · 接触角分析与表面能计算

一、总体流程

本软件把“仪器报告 → 数据提取 → 配对计算 → 结果导出” 串成一条自动化流程，减少手工抄录与公式计算。

  1. 在首页点击需要使用的功能，或在菜单“计算方法”中切换
  2. 导入仪器导出的 Word 报告
  3. 在表格中核对数据，必要时手动修正或补充
  4. 点击“计算”得到结果
  5. 导出为 Excel 文件

二、表面能计算

1. 导入数据

  • 点击 导入水滴角，选择所有水滴角 Word 文件
  • 点击 导入二碘甲烷接触角，选择所有二碘甲烷 Word 文件
两个导入按钮都支持多选，导入顺序不影响结果。 软件会自动从报告中提取“平均角度”。
若部分文件未能提取到角度，程序会弹出 导入失败明细 窗口， 逐条列出“文件名 + 原因”，可一键复制。

2. 自动配对规则

软件按文件名进行配对：去掉扩展名后文件名一致，视为同一样品。

  • 水滴角 4.doc 与 二碘甲烷 4.doc → 配成一行
  • 文件名不同 → 视为不同样品，各自独立成行
请确保水滴角与二碘甲烷的文件名一致，否则不会被自动合并。

3. 表格列说明

列名可编辑说明
序号否来源文件名（去扩展名），用于定位原始数据
样品是可输入数字、汉字、字母、符号等任意文本
水接触角是只能输入数字，需在 0°–180° 之间
二碘甲烷接触角是只能输入数字，需在 0°–180° 之间
极性分量 / 色散分量 / 估值方法 / 表面能否由计算自动生成
「序号」列是软件的内部标识，不会导出到 Excel。 修改「样品」列的名字不会影响配对与删除逻辑。

4. 表格操作

  • 单击单元格：选中该单元格
  • 单击左侧行号：选中整行；Ctrl 加选、Shift 连续选择
  • 双击单元格：进入编辑
  • 按 Delete：清空选中单元格内容
  • 点击表格下方 + 号：在末尾追加一行空行
  • 右键菜单：
    • 删除选中单元格内容
    • 删除选中行
    • 在上方 / 下方插入多行（可设置数量）
    • 清空全部数据

5. 计算与导出

  • 点击 计算表面能：按 OWRK 模型计算，结果写入后四列
  • 点击 导出.xlsx文件：将当前表格内容导出为 Excel
如果某行只有一种角度，该行会保留但后四列留空； 计算完成时会提示成功配对、缺少数据的行数。

6. 关于「计算失败」

OWRK 方程并非对所有接触角组合都有实数解。当水接触角偏大 （约 > 96°）而二碘甲烷接触角偏小时，方程无解，属于模型适用范围 问题，不是程序错误。

出现该情况时，程序会在计算完成提示中列出具体样品名与原因， 不会静默留空。请核对数据，或确认两种角度没有填反。

三、导电性计算

  • 依次输入 样品名称、电阻 R (Ω)、长度 L (cm)、横截面积 A (cm²)
  • 点击 计算：结果追加到下方表格
  • 电阻率 ρ = R·A / L (Ω·cm)，电导率 σ = 1/ρ (S/cm)
  • 点击 导出.xlsx文件：导出所有已计算记录
输入框只接受数字（支持科学计数法如 1e-5）； 表格中显示 4 位小数 / 6 位有效数字，导出的 Excel 保存完整精度数值。

四、常见问题

导入时提示“未在文件中提取到有效接触角”

  • 确认文件是仪器原始导出的 Word 报告
  • 确认报告里存在“平均角度”或“平均接触角”字段
  • 本机需安装 Microsoft Word 或 WPS，读取 .doc 依赖 Office
  • 点击提示窗口中的 导入失败明细 可查看每个文件的具体原因

计算后两行没有合并

  • 检查水滴角与二碘甲烷的文件名是否一致（去扩展名后）
  • 若使用了后缀（如 -I），请改名后再导入

某行显示“计算失败”

  • 该角度组合超出 OWRK 模型适用范围（方程无实数解）
  • 检查是否把水接触角与二碘甲烷接触角填反了

导出后 Excel 里是空行

  • 导出时会自动过滤全空行，只有含内容的行才会写入

导出时提示“无法写入文件”

  • 目标文件正在 Excel 中打开，请关闭后重试
  • 或换一个没有写入限制的位置（如桌面）

程序异常退出

  • 菜单 帮助 → 打开日志文件夹 可查看崩溃与运行日志
  • 反馈问题时请附上当天日志文件

五、环境与打包

  • 运行环境：Windows + Python 3.9 及以上 + PySide6
  • 读取 .doc 需要本机安装 Microsoft Word 或 WPS
  • 打包：双击 build.bat（内部使用 YG-DATA.spec）
